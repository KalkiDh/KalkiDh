<td width="50%" valign="top">

**🩺 AI Answer Evaluation Pipeline**
<br/>
<sub>Ontario Tech University</sub>

**Problem:** Grading test responses from PDFs with wildly inconsistent layouts made manual review slow and error-prone.

**Aim:** Automate evaluation accurately across hundreds of document formats.

**Solution:** A fault-tolerant, multithreaded NLP pipeline — cut manual review by **70%** across **500+** document types.

</td>
<td width="50%" valign="top">

**📊 Institutional Analytics Platform**
<br/>
<sub>SRM Institute of Science and Technology</sub>

**Problem:** 5+ years of placement data lived in silos, impossible to query quickly.

**Aim:** Give 50+ stakeholders instant, natural-language access to institutional data.

**Solution:** A FastAPI + React + MongoDB platform with a RAG-powered chatbot, turning hours-long lookups into seconds.

</td>
</tr>
<tr>
<td width="50%" valign="top">

**✈️ Multi-Tenant Conversational Booking Agent**
<br/>
<sub>Odysseus Solutions Pvt. Ltd.</sub>

**Problem:** A cruise booking engine needed a secure, autonomous assistant at massive scale, without leaking data across tenants.

**Aim:** Resolve complex customer workflows automatically while enforcing strict data isolation and compliance.

**Solution:** A LangChain/LangGraph agentic system integrating 90+ APIs with RBAC — **85%** query resolution with zero human escalation, GDPR-compliant, serving **100K+ daily users** across 40+ countries.

</td>
<td width="50%" valign="top">

<sub>SRM Career Catalyst</sub>

**Aim:** Recommend the right opportunities using semantic understanding, not keyword matching.

**Solution:** An NLP + Random Forest + FAISS recommendation engine matching 700+ student profiles to 200+ company roles — **92%** pilot engagement.
